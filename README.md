# odin-calculator
Last project of The Odin Project's foundations

## Why?
This project tested my JavaScript skills on DOM Manipulation and inner logic. To make a working calculator requires both understanding of JavaScript and persistance to polish bugs.

## Final Reflection
This was easily the website that has consumed the most time of any of the TOP projects so far. There were so many small details that I had to pay attention to. It was all very fun though, overall finding out what was making the bugs and really understanding why it wasn't working (the process of testing was fairly tedious, but figuring it out was really fun).
